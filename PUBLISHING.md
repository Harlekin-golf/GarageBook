# Публикация GarageBook (общая инструкция)

Приложение — набор статических файлов без сборки и серверной части. Подойдёт любой статический хостинг с https (GitHub Pages, Netlify, Cloudflare Pages, свой сервер).

## Файлы для загрузки
`index.html`, `sw.js`, `manifest.webmanifest`, `logo.webp`, `icon-192.png`, `icon-512.png`, `apple-touch-icon.png`, `.nojekyll` (нужен только для GitHub Pages).
Все файлы лежат в корне; пути в манифесте и service worker относительные, поэтому приложение работает и в подпапке адреса.

## Важно про адрес
Данные пользователя хранятся в браузере и привязаны к адресу (origin: схема + домен + порт). Разные приложения на одном домене делят одно хранилище, поэтому для разных приложений лучше использовать разные домены или поддомены.

## Проверка после публикации
1. Откройте адрес сайта: должна открыться шапка с логотипом и название «Моя машина».
2. Откройте `/manifest.webmanifest` — должен показаться текст манифеста.
3. Установите приложение (на iPhone: «Поделиться» → «На экран Домой»), включите авиарежим и откройте — приложение должно работать.

## Обновление
1. Перед обновлением сохраните резервную копию из приложения.
2. Замените изменённые файлы.
3. В `sw.js` увеличьте номер в первой строке (`const V = 'sk-pub-1';` → `'sk-pub-2'`), иначе установленные копии обновятся не сразу.
4. Подождите 1–2 минуты и откройте приложение; новая версия может подтянуться после повторного запуска.

## Откат
Верните прежние версии файлов и увеличьте номер в `sw.js` ещё раз.
