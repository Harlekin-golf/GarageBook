GarageBook — всё о твоём автомобиле
Сервисная книжка: записи обслуживания и ремонта, расходы, заправки, напоминания, фото. Приложение работает в браузере и устанавливается на телефон как PWA. Данные хранятся только на вашем устройстве (в браузере), на сервер ничего не отправляется.

ЛОКАЛЬНЫЙ ЗАПУСК И ПРОВЕРКА
1. Распакуйте архив в отдельную папку.
2. Откройте терминал в этой папке и запустите любой простой веб-сервер, например:
   Windows:  py -m http.server 8080
   macOS/Linux:  python3 -m http.server 8080
3. Откройте в браузере http://localhost:8080/ (service worker и установка работают только на localhost или https; двойной щелчок по index.html не подходит).
4. Для проверки с телефона в той же сети откройте http://<адрес компьютера>:8080/ (без https установка PWA и офлайн на телефоне недоступны — это ограничение браузера).
5. Первый запуск: название «Моя машина», поля автомобиля и метка пусты, галерея пуста. Остальные функции доступны сразу.
6. Офлайн: откройте приложение один раз, затем выключите сеть и обновите страницу.
7. Резервная копия: Настройки → резервная копия / восстановление.

ТЕМЫ
Тёмная (по умолчанию) и светлая переключаются в настройках.

ФАЙЛЫ
index.html, sw.js, manifest.webmanifest, logo.webp, icon-192.png, icon-512.png, apple-touch-icon.png, .nojekyll.
Данные приложения (локальное хранилище браузера и IndexedDB) привязаны к адресу сайта: на другом адресе приложение начинает с пустого состояния. Для переноса используйте резервную копию.
